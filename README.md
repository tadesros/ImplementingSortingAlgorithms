# ImplementingSortingAlgorithms
Produce an algorithm which implements sorting algorithms


Project Overview:

This project was a final assignment in my Algorithm Analysis course.  

The purpose of this project was to produce a program that implements the following sorting algorithms:
Bubble
Merge
Quick
Heap

​I chose to complete the project using a Windows console application in C++.

The program begins by asking the user to enter the array size (list) to be created.  The program creates a dynamic array of random numbers (using the built in  rand() function).   The program displays a menu for the user to choose a sorting algorithm.  The program performs the sort by calling the appropriate function by that name and displays the output.
